# THE WRONG SIDE — Award-focused visual redesign

**Deliverable:** 12 editable SVG website artboards (desktop 1440×900, mobile 390×844), PNG rendered previews, contact sheets and a local HTML review page. This is a redesigned static design system, **not a working website, an Awwwards score, or a fully solved cloth simulation**.

## Visual changes from V1
- Condensed, high-contrast Didot-style display composition, warm paper, ink plum, indigo, rust and saffron.
- Entrance maintains the selected frayed-fabric image, with improved hierarchy and interaction affordance.
- Loom is an original *editable vector* material with rows, crossing geometry and a shuttle, rather than flat colored squares.
- Reverse is a material inspection experience: gallery-scale fabric and accessible flip control, with an educational plain-weave schematic on desktop and mobile.
- Pattern Room: entirely different composition, full-bleed textile graphic and a single tool tray.
- Collection: verified record from The Metropolitan Museum of Art, **with clearly labeled original illustrative fabric study**, not a false photo of the museum object. Replace with actual public-domain image of the correct object before release.
- Edition: art-directed printed object, nonrepeating artwork composition, intentional paper and export options.
- No arbitrary screen/chapter numbering, fake technical readouts or repeated card grid structure.

## Editing
SVGs have native text, paths, circles, rectangles and stroke geometry. The Entrance and Reverse share an embedded raster *concept image* from the previously selected hero; everything else is largely SVG vector. When imported into Figma, some browsers/design tools may substitute the intended **GFS Didot** font. Assign a licensed high-contrast display face in your own Figma environment if needed. No font files are included.

## Rights and truth
The hero textile is a previously generated **concept image**, not a real museum artifact or a mathematically verified reverse face. The vector Loom models alternating crossings as an instructional illustration, **not industrial yarn dynamics**. The Pattern and Edition weave texture is an original vector art direction surface. The Collection uses a verified factual record but **NOT** the actual object's image. The source image must be curated and downloaded from the verified museum page for final delivery. Never present our constructed motif as Japanese ikat.

Museum record: https://www.metmuseum.org/art/collection/search/45411 — Piece of Cloth for Bedding; Japan; nineteenth century; plain-weave cotton with weft kasuri (ikat) patterning; accession 66.122.20; public domain.
