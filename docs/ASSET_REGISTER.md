## Pattern Room implementation — 2026-10-12

- `public/images/pattern-room-desktop.webp` (2160×1221, about 309 KB) and `pattern-room-mobile.webp` (585×879, about 92 KB): original procedural Canvas cutwork studies generated by `scripts/prepare-pattern-fallbacks.ts` from the initial `makeLoomArtwork()` yarns and crossings. They are responsive first-paint/no-JavaScript posters only; live visitor artwork is rendered from the current shared data. No external image source, third-party rights or historical attribution applies.
- `src/lib/pattern-renderer.ts`: original Canvas cut shapes for Cutwork, Ribbon and Bias, using stable physical 8-end × 4-pick samples from the current visitor textile. Desktop and mobile paths are independently authored from the approved internal SVG art direction. Source yarn geometry comes from the same `renderer.ts` used by Loom and Reverse; the shape edges, stacking light and shadows are graphic approximations. Repeated cuttings are finite and do not imply seamless physical interlacement at graphic tile boundaries.
- Approved `Design/pattern-room-desktop.svg` and `pattern-room-mobile.svg` remain internal editable references. Neither artboard is shipped as the page or used as a raster screenshot interface.

## Public-domain/institutional source shortlist

Prototype update (2026-10-11): GFS Didot Regular is now bundled at `public/fonts/GFSDidot-Regular.ttf`, with `public/fonts/OFL-GFS-Didot.txt`, downloaded from the official Google Fonts `ofl/gfsdidot` directory. UI uses the system Arial fallback; Arimo/Cousine remain planned, not bundled. The engine renders original procedural yarns and uses no museum or generated textile images.

- [The Metropolitan Museum of Art Open Access](https://www.metmuseum.org/about-the-met/policies-and-documents/open-access): best direct fit; object record provides image and data in public domain.
- [Smithsonian Open Access](https://www.si.edu/openaccess): search textile collections; verify each item’s CC0/public-domain status and object metadata individually.
- [Library of Congress Prints & Photographs](https://www.loc.gov/pictures/): useful for historic textile/fashion prints and digitized materials; check rights advisory per item rather than assuming all holdings are public domain.
- [V&A Collections](https://www.vam.ac.uk/collections): strong textile/fashion catalog and high-quality images; check image-level reuse terms, because collection presence alone does not imply public-domain rights.

## Weave fact basis

- Plain weave: each weft passes over/under successive warp yarns; adjacent picks reverse the crossing.
- Twill: floats progress in a regular offset to create diagonal ribs/ridges; label the repeat (e.g. 2/1 or 2/2) only when the diagram’s lift plan implements it.
- Satin: long floats with dispersed interlacings; “satin” names the structure, not fiber. Warp-faced satin and weft-faced sateen differ by which system dominates the face. Do not depict satin as a simple diagonal twill.
- Source: [GWU Textile Museum glossary](https://museum.gwu.edu/textile-terms), [Pratt Textile Research Lab woven structures](https://textileresearchlab.pratt.edu/construction/wovens).
